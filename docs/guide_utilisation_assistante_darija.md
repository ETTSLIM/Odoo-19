  <p style="margin: 0; font-size: 15px; color: #6e6e73;">هاد الدليل مديور بدارجة مغربية ساهلة وجمل قصيرة، باش تعرفي كيفاش تدوز الطوموبيل من نهار تدخل حتى تخرج مخلصة وناضية.</p>

<div style="background: #ffffff; border-radius: 16px; padding: 22px; border: 1px solid #e5e5ea; margin-bottom: 22px; box-shadow: 0 2px 8px rgba(0,0,0,0.02);">
  <h2 style="margin-top: 0; font-size: 20px; color: #1d1d1f; border-bottom: 2px solid #0071e3; padding-bottom: 8px; display: inline-block;">📌 1. القوائم لي غاتحتاجي بزاف ف السيستيم</h2>
  <p style="color: #424245; font-size: 14.5px;">فاش كتدخلي لـ <b>Garage Pro</b>، كاينين 3 ديال البلايص مهمين ف الموني الفوقاني:</p>
  <ul style="padding-right: 20px; margin-bottom: 0;">
    <li style="margin-bottom: 8px;"><b>Tableau Atelier & Entrées :</b> الطابلو العام لي كيبين كاع الطوموبيلات وفين واصلين مرحلة بمرحلة.</li>
    <li style="margin-bottom: 8px;"><b>Ordres de Travaux & BL :</b> البلاصة لي فيها أوامر الإصلاح، البياس، والبونات د الخلاص.</li>
    <li><b>Sinistres & Assurances :</b> البلاصة ديال الطوموبيلات د الكسيدة لي دافعين دوسي مع شركات التأمين والخبراء.</li>
  </ul>

<div style="background: #ffffff; border-radius: 16px; padding: 22px; border: 1px solid #e5e5ea; margin-bottom: 22px; box-shadow: 0 2px 8px rgba(0,0,0,0.02);">
  <h2 style="margin-top: 0; font-size: 20px; color: #1d1d1f; border-bottom: 2px solid #34c759; padding-bottom: 8px; display: inline-block;">🔄 2. دورة حياة الطوموبيل (7 ديال المراحل واضحة)</h2>

  <div style="margin-top: 18px; border-right: 4px solid #0071e3; padding-right: 14px; margin-bottom: 20px;">
    <h3 style="margin: 0 0 6px 0; font-size: 17px; color: #0071e3;">المرحلة 1: الدخول والتقليب الأول (Réception & Diagnostic)</h3>
    <ul style="padding-right: 18px; margin: 0; color: #333336; font-size: 14px;">
      <li>كتدخلي لـ <b>Tableau Atelier & Entrées</b> وتكليكي على <b>Créer</b> (جديد).</li>
      <li>كدخلي الماتريكول ديال الطوموبيل (License Plate).</li>
      <li>كدخلي سمية الكليان ونمرة الواتساب ديالو (ضروري تكون صحيحة).</li>
      <li>كتقيدي الكيلومتراج ونيڤو د المازوط ولا ليصانص ف الخانات ديالهم.</li>
      <li>كتسجلي شكوى الكليان والمشكل لي عندو ف خانة الأعراض.</li>
      <li>كتاخدي تصاور ب التيليفون ولا الطابليط لأي حكة ولا ضربة ف الكاروسري وكتلوحيهم ف السيستيم (لحماية الكراج).</li>
      <li>كتختاري التخصص (ميكانيك، طولي، تريسيان، فيدونج...) والسيستيم كيخرج ليستة د الخدمة أوتوماتيك.</li>
    </ul>
  </div>

  <div style="border-right: 4px solid #5856d6; padding-right: 14px; margin-bottom: 20px;">
    <h3 style="margin: 0 0 6px 0; font-size: 17px; color: #5856d6;">المرحلة 2: الدوڤي وموافقة الكليان / التأمين (Devis & Accord)</h3>
    <ul style="padding-right: 18px; margin: 0; color: #333336; font-size: 14px;">
      <li>كتقيدي ملاحظات الدياڭنوستيك ف خانة البياس وتكليكي <b>"Transmettre au Stock"</b> باش المازانازيي يسعر البياس.</li>
      <li>ملي كيوجد الحساب، كتكليكي على زر <b>WhatsApp</b> باش يصيفط رابط الدوڤي للكليان مباشرة.</li>
      <li>الكليان كيكليكي ف الرابط على <b>"موافق" (Valider en 1-Clic)</b>، والسيستيم كيسجل تاريخ الموافقة ديالو.</li>
      <li><b>إلا كانت كسيدة د التأمين (Sinistre Assurance) :</b>
        <br/>كتكليكي على <b>"Créer Sinistre"</b>، كتقيدي نمرة الدوسي، الخبير، وشركة التأمين، وكتسناي محضر الخبير وموافقة الكليان على الفرانشيز.</li>
    </ul>
  </div>

  <div style="border-right: 4px solid #ff9500; padding-right: 14px; margin-bottom: 20px;">
    <h3 style="margin: 0 0 6px 0; font-size: 17px; color: #ff9500;">المرحلة 3: كوموند وتوفير البياس (Commande & Attente Pièces)</h3>
    <ul style="padding-right: 18px; margin: 0; color: #333336; font-size: 14px;">
      <li>هاد المرحلة كيتكلف بيها المازانازيي بالأساس.</li>
      <li>دورك هو تراقبي الستاتي ف الشاشة حتى يولي أخضر: <b>"Pièces Disponibles"</b> (البياس وصل لاتيليي).</li>
    </ul>
  </div>

  <div style="border-right: 4px solid #ff3b30; padding-right: 14px; margin-bottom: 20px; background: rgba(255, 59, 48, 0.04); padding: 12px; border-radius: 8px;">
    <h3 style="margin: 0 0 6px 0; font-size: 17px; color: #ff3b30;">المرحلة 4: الخدمة ف لاتيليي (Travaux d'Atelier en Cours)</h3>
    <ul style="padding-right: 18px; margin: 0; color: #333336; font-size: 14px;">
      <li>المعلمية (الميكانيكيين، التولارية، التريسيانات) كيبداو الإصلاح الفعلي.</li>
      <li>كل معلم كيڤاليدي المهام ف الطابليط بكود سري ديالو (<b>Code PIN</b>).</li>
      <li><b>⚠️ نظام الأمان الصارم (Safety Interlock) :</b><br/>السيستيم مكيسمحش للطوموبيل تدوز لهاد المرحلة إلا إلا كان الكليان وافق على الدوڤي، ولا لاسيرونس وافقت ف حالة الكسيدة. بلا موافقة السيستيم كيبلوكي باش ما نضيعوش ف الفلوس.</li>
    </ul>
  </div>

  <div style="border-right: 4px solid #af52de; padding-right: 14px; margin-bottom: 20px;">
    <h3 style="margin: 0 0 6px 0; font-size: 17px; color: #af52de;">المرحلة 5: الكونطرول والتجربة (Contrôle Qualité & Essai)</h3>
    <ul style="padding-right: 18px; margin: 0; color: #333336; font-size: 14px;">
      <li>الشاف د لاتيليي كيدير تجربة للطوموبيل ف الطريق ف السرعة والفران.</li>
      <li>كيدوزو السكانير (OBD) باش يتأكدو بلي ما بقا حتى ديفو شاعل ف الطابلو.</li>
      <li>كيڤاليديو خانة المراقبة بنجاح ف السيستيم.</li>
    </ul>
  </div>

  <div style="border-right: 4px solid #34c759; padding-right: 14px; margin-bottom: 20px;">
    <h3 style="margin: 0 0 6px 0; font-size: 17px; color: #34c759;">المرحلة 6: واجدة للتسليم (Prête pour Livraison)</h3>
    <ul style="padding-right: 18px; margin: 0; color: #333336; font-size: 14px;">
      <li>الطوموبيل كتمشي للغسيل (Lavage) وكترجع نقية لداخل وبرا.</li>
      <li>غير كتحطيها ف مرحلة <b>"Prête"</b>، السيستيم كيصيفط ميساج واتساب أوتوماتيك للكليان يقول ليه: <i>"طوموبيلتك واجدة ومغسولة وموجودة ف الكراج"</i>.</li>
      <li>إلا كانت ديال لاسيرونس، كطبعي ليه <b>"شهادة التوقيف" (Attestation d'immobilisation)</b> باش يدفعها لتعويض أيام التوقف.</li>
    </ul>
  </div>

  <div style="border-right: 4px solid #1d1d1f; padding-right: 14px; margin-bottom: 10px;">
    <h3 style="margin: 0 0 6px 0; font-size: 17px; color: #1d1d1f;">المرحلة 7: الخروج والخلاص (Livrée & Clôturée)</h3>
    <ul style="padding-right: 18px; margin: 0; color: #333336; font-size: 14px;">
      <li>كتدخلي لـ <b>Ordre de Travaux</b>.</li>
      <li>كطبعي <b>بون الخدمة (BL)</b> للكليان العادي، ولا <b>الفاكتور الرسمية</b> إلا كان باغي فاكتور بالضريبة (TVA 20%).</li>
      <li>كتسجلي الخلاص ف خانة الأداءات: كاش (Espèces)، كارط بانكير (TPE)، ولا شيك (Chèque).</li>
      <li><b>⚠️ تنبيه مهم :</b> أي خلاص داز بـ TPE ولا شيك، ضروري تكون خارجة فاكتور رسمية ومقادة باش الحسابات البنكية تكون مطابقة قانونيا.</li>
      <li>كتسني الكليان ف بون الخروج، كتسلميه السوارت، وكتسدي الدوسي ف السيستيم.</li>
    </ul>
  </div>

  <h2 style="margin-top: 0; font-size: 20px; color: #1d1d1f; border-bottom: 2px solid #ff9500; padding-bottom: 8px; display: inline-block;">⭐ 5 ديال القواعد الذهبية للمساعدة (ما تنسايهمش قطعا)</h2>
  
  <ol style="padding-right: 20px; margin-bottom: 0; color: #1d1d1f; font-size: 14.5px; line-height: 2;">
    <li><b>نمرة الواتساب ف الدخلة :</b> ضروري تكون نمرة خدامة باش كل إشعار يوصل للكليان أوتوماتيك بلا ما تعيطي.</li>
    <li><b>التصاور عند الاستقبال :</b> أي ضربة ف الباب، كسايد قدام، ولا زاج مشقوق صوريه لحماية الكراج.</li>
    <li><b>الكيلومتراج والمازوط :</b> قيديهم قدام الكليان نهار يحط السوارت.</li>
    <li><b>ما كاينش تفكيك بلا موافقة :</b> ديما تأكدي بلي الكليان راه دار "Accord" ف الواتساب عاد الطوموبيل تبدا ف لاتيليي.</li>
    <li><b>الخلاص قبل السوارت :</b> ما كيتسلمو السوارت حتى كيكون الحساب مسجل ومسدود كامل ف السيستيم.</li>
  </ol>
